Registry / least privilege

Tools with boundaries.

Every MCP entry declares purpose, transport, authentication, read tools, write tools, confirmation rules, data scope, secret environment variables, installation status, validation command, and fallback.

Defaults

  • No credentials in source.
  • Read and write surfaces remain separate.
  • Unavailable tools never produce invented results.
  • External writes require explicit authority.
  • Every server has a smoke test or documented fallback.
Machine-readable registry: mcp/registry.yml
